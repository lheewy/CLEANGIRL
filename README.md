# ✨ Inspirée — Protocole Clean Girl

Concept d'application web PWA minimaliste, épurée et haut de gamme conçue pour structurer une transformation profonde sur 90 jours.

## 🎨 Caractéristiques
- **Design Premium** : Palette Sable, Beige, Terra-cotta et touches Vert Sauge.
- **Flexibilité** : Interface glissante (Drag & Drop tactile) pour réordonner son planning à la volée.
- **Sécurité** : Écran de verrouillage par code PIN de 4 à 6 chiffres pour protéger son journaling.
- **Mondial** : Synchronisation instantanée basée sur l'adresse email.
- **Focus Temporel** : 1h d'impulsion le matin (5h) et 15-30 min d'ancrage le soir.
